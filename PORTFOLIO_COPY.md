## Project title

**Kalshi 10×1¢ Public Edition — Responsible Automation Case Study**

## One-line description

A verification-led Python application that turns a simple order concept into a transparent, testable workflow with dry-run exploration, fixed limits, and deliberate production controls.

## Professional description

I created the Kalshi 10×1¢ Public Edition to demonstrate how thoughtful information management can make automation easier to understand and trust. The application organizes market data into clear order plans, applies a consistent decision policy, and gives users a credential-free dry-run path before they consider any account-connected workflow.

The project brings together API integration, data validation, documentation, privacy controls, and release governance. Every permitted order follows the same fixed profile: 10 contracts at a 1¢ economic price. A tracked stop control, source-integrity verification, account preflights, a persistent 80-contract session limit, and 113 automated tests make the system's boundaries visible and repeatable.

This is an educational engineering project, not a performance claim. Demo and production modes are advanced paths, and the application presents conditional payoff arithmetic alongside fees, fill uncertainty, and principal-at-risk information.

## Case-study summary

**Opportunity:** Make a compact automation concept understandable and inspectable for a broader audience.

**Approach:** Reduce the workflow to one clearly defined order profile, build in consistent data and account checks, isolate credentials, preserve uncertain outcomes for review, and document a safe learning path from scan to dry run.

**Result:** A polished technical showcase that demonstrates the same strengths I bring to information-management work: clear requirements, governed data, traceable decisions, practical controls, and documentation people can use.
